# Homebrew Tap for NeoNV

This tap provides Homebrew Cask formulas for NeoNV and related tools.

## Installation

```bash
brew install --cask msnodderly/tap/neonv
```

Or tap first, then install:

```bash
brew tap msnodderly/tap
brew install --cask neonv
```

## Available Casks

- **neonv** - Fast, frictionless text capture for macOS

## About

NeoNV is a native macOS app for instant text capture and retrieval, inspired by Notational Velocity.

For more information, see the [main repository](https://github.com/msnodderly/neonv).
